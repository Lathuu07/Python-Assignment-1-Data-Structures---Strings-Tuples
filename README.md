# Python Assignment 1 – Data Structures: Strings & Tuples

## 📌 Overview
This repository contains Python Assignment 1, focusing on fundamental Python data structures: Strings and Tuples.

The assignment covers string operations, indexing, slicing, built-in string methods, tuple creation, concatenation, repetition, and accessing tuple elements.

## 🎯 Objectives
- Understand string concatenation.
- Learn string indexing and slicing.
- Perform string manipulation using built-in methods.
- Understand tuple creation and accessing elements.
- Perform tuple concatenation and repetition.

## 🐍 Topics Covered

### 1. String Concatenation
- Creating string variables.
- Getting user input using `input()`.
- Combining multiple strings using the `+` operator.

### 2. String Slicing and Indexing
- Accessing the first and last characters.
- Extracting the first five and last eleven characters.
- Reversing a string.
- Extracting a specific word using slicing.

### 3. String Methods
Practised the following built-in string methods:
- `upper()` – Converts a string to uppercase.
- `lower()` – Converts a string to lowercase.
- `capitalize()` – Capitalizes the first character.
- `count()` – Counts character occurrences.
- `replace()` – Replaces specific words or characters.

### 4. Tuples – Creation, Concatenation and Access
- Creating tuples.
- Concatenating two tuples using `+`.
- Repeating tuple elements using `*`.
- Accessing elements using indexing.
- Extracting elements using slicing.
